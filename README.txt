### Coffee Sales Analysis

This is a simple Data Analysis mini project for analyzing coffee shop sales data and finding useful operational insights. 

### Features

* Transaction ID
* Order Date
* Customer Name
* Coffee Type (e.g., Espresso, Latte, Cappuccino)
* Coffee Variety / Beans (e.g., Arabica, Robusta)
* Size (Small, Medium, Large)
* Quantity Ordered
* Total Unit Price
* Total Bill Amount
* Customer Type (Member / Walk-in)
* Payment Method (Cash, Credit Card, Mobile Wallet)

### Target / Analysis

The project analyzes: 

* Total Orders Placed
* Total Revenue Generated
* Total Repeat Members
* Most Popular Coffee Types
* Highest-Selling Coffee Varieties
* Peak Sales Months and Hourly Trends
* Revenue Breakdown by Product Size
* Sales Performance: Member vs. Walk-in Customers
* Preferred Payment Methods by Revenue

### Algorithm / Technology

Python Data Analysis Libraries used: 

* Pandas
* NumPy
* Matplotlib
* Seaborn

### Files

* app.py
* coffee_sales_data.csv
* requirements.txt
* README.md

### How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install required libraries using: pip install -r requirements.txt
4. Run the application using: python app.py
